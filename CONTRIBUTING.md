# Contributing to Oh-Shit

Thanks for helping improve this OSINT toolkit reference.

## Contribution Scope

Good contributions include:

- New legitimate OSINT resources.
- Dead-link fixes.
- Better categorization and concise descriptions.
- Duplicate cleanup and formatting consistency.

Please avoid:

- Promotional submissions.
- Unverified or suspicious links.
- Entries that encourage illegal or unethical behavior.

## Entry Format

Each category table uses:

`Tool | URL | Access | Notes`

Use one of these access labels:

- `Free`
- `Freemium`
- `Paid`
- `Unknown`

## Quality Checklist

Before submitting:

- [ ] Link resolves to the intended destination.
- [ ] Description is concise and neutral.
- [ ] Category is appropriate.
- [ ] Duplicate entries are removed or justified.
- [ ] Privacy-risk tools include caution notes.
- [ ] Markdown table formatting is valid.

## Pull Request Guidance

- Keep PRs focused on one area (for example, one category or one cleanup type).
- Summarize what changed and why.
- Mention any removed entries and rationale.

## Responsible Use Reminder

By contributing, you agree that this repository should support legitimate research and investigations only. Review [`RESPONSIBLE_USE.md`](/RESPONSIBLE_USE.md) for standards contributors are expected to follow.
