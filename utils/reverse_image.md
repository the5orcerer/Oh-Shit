# Reverse Image

Resources for reverse-image lookup, source tracing, and visual verification.

| Tool | URL | Access | Notes |
| --- | --- | --- | --- |
| Google Images | https://images.google.com/ | Free | Reverse-image and related-image discovery. |
| Bing Visual Search | https://www.bing.com/visualsearch | Free | Image similarity and object-level search. |
| Yandex Images | https://yandex.com/images/ | Free | Strong reverse-image matching for many regions. |
| TinEye | https://tineye.com/ | Freemium | Reverse-image index with image appearance tracking. |
| Baidu Images | https://image.baidu.com/ | Free | Chinese-language image search and matching. |
| ImgOps | https://imgops.com/ | Free | Meta-search portal for multiple reverse-image engines. |
| SauceNAO | https://saucenao.com/ | Freemium | Source lookup for images and artwork references. |
| Google Lens | https://lens.google.com/ | Free | Visual object/entity recognition and web matching. |
