# Maps

Geospatial and mapping tools for location-based investigations.

| Tool | URL | Access | Notes |
| --- | --- | --- | --- |
| Google Maps | https://maps.google.com/ | Free | Global map and place intelligence platform. |
| Bing Maps | https://www.bing.com/maps | Free | Mapping and satellite imagery by Microsoft. |
| Yandex Maps | https://yandex.com/maps/ | Free | Regional mapping and geospatial search. |
| DuckDuckGo | https://duckduckgo.com/ | Free | Includes map and location search results. |
| Sentinel Hub Playground | http://apps.sentinel-hub.com/sentinel-playground | Freemium | Satellite imagery exploration tool. |
| geOps Mobility Portal | https://mobility.portal.geops.io/ | Free | Real-time transit movement visualization. |
| MapChannels Dual Maps | http://data.mashedworld.com/dualmaps/map.htm | Free | Compare multiple map views side-by-side. |
| Mapillary | https://www.mapillary.com/ | Freemium | Street-level imagery and map data platform. |
| KartaView | https://kartaview.org/landing | Freemium | Crowdsourced street-level imagery map. |
| OpenStreetMap | https://www.openstreetmap.org/ | Free | Open geospatial map data project. |
| CityProtect | https://cityprotect.com/map/ | Free | Crime and incident map aggregation for participating cities. |
